# visual/references/

The canonical, **frozen** reference art and drawings. Work in progress does not belong here —
only material that has passed its acceptance checklist.

| Directory | Holds | Gate |
|---|---|---|
`character/` | The nine canonical views of TF_TRADER_01, plus the generated construction sheet | `CHARACTER_BIBLE.md` §5 — any single failure rejects the plate |
`office/` | The seven canonical plates of TRADE_FIX_OFFICE_01, plus the generated plan | `OFFICE_BIBLE.md` §10, cross-checked against the CAM 5 wide plate |
`motion/` | Reference clips for the motion reference sheet | `MOTION_LIBRARY.md` §14 |

## Generated, not drawn

| File | Generated by |
|---|---|
`office/TRADE_FIX_OFFICE_01_plan.svg` | `scripts/visual/render_reference_svg.py` |
`character/TF_TRADER_01_proportions.svg` | same |

Both derive from the blockout, so they cannot drift out of agreement with the geometry. Re-run
the script after any blockout change rather than editing the SVG.

`index.html` is a convenience viewer: serve this directory over HTTP and open it. Not a
deliverable.

## Painting order is an order

View 1 — the front portrait — is painted and accepted **first**, and becomes the identity
reference for the other eight. If a later view cannot be made to match it, view 1 is **not**
re-opened; the later view is repainted. That is the whole mechanism by which one man appears in
nine drawings.
